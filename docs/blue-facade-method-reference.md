# Public API reference

The former method-by-method façade inventory has been replaced by the
reproducible [distribution API inventory](reference/public-api.md). Start with
the [ten-minute guide](start-here.md), then use the generated inventory and
package Javadocs for exact signatures.

The aggregate `Blue` class is intentionally a small convenience delegate. New
applications should prefer the focused `BlueLanguage`, `BlueContracts`, and
`BlueRuntime` composition roots shown by the tested [`:examples`](../examples)
module.
